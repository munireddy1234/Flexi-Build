# Flexi Build

**Build your ideal device, your way.**

Flexi Build is a customizable electronics platform that helps users configure laptops, desktop PCs, and mobile phones according to their needs, preferences, and budget.

## 🎯 Project Goal

Make it easier for users to explore device specifications, customize configurations, compare options, and choose devices that fit their requirements and budget.

## ✨ Planned Features

- 💻 Laptop configuration
- 🖥️ Desktop PC builder
- 📱 Mobile phone customization
- 💰 Budget-based recommendations
- ⚙️ PC component compatibility checks
- 📊 Price estimation and device comparison

## 🛠️ Technology Stack

- Python
- FastAPI
- PostgreSQL
- SQLAlchemy

## 🚧 Project Status

**Currently in development.**

Backend development has started. Frontend integration and additional configuration features are planned.
