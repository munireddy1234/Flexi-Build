# Flexi Build

Flexi Build is a customizable electronics platform that helps users design and configure laptops, desktop PCs, and mobile phones according to their needs, preferences, and budget.

## Project Overview

Flexi Build aims to make choosing and customizing electronic devices easier by allowing users to explore specifications, compare options, and build configurations suited to their requirements.

## Planned Features

- **Laptop Builder:** Customize available laptop specifications and features.
- **PC Builder:** Select compatible hardware components such as processors, graphics cards, RAM, and storage.
- **Mobile Phone Builder:** Explore and customize supported phone specifications and features.
- **Budget-Based Recommendations:** Find suitable configurations based on the user's budget.
- **Compatibility Checks:** Identify incompatible PC components and configuration conflicts.
- **Price Estimation:** Calculate estimated prices for selected configurations.
- **Device Comparison:** Compare specifications, features, and prices.

## Technology Stack

- Python
- FastAPI
- PostgreSQL
- SQLAlchemy
